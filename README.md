# Игры для Тимура

Три маленькие игры для сына, 5 лет. Проиграть нельзя ни в одной, читать не нужно.

- **Трактор** — вести трактор пальцем по полю и собирать урожай. 5 уровней, потом бесконечно.
- **Котята** — найди пару: Коржик, Карамелька, Компот и предметы. 4 уровня.
- **Пицца** — собрать заказ из ингредиентов. 5 заказов.

Открывать с главной страницы: карточки ведут в игры.
Всё рисуется кодом, звук — WebAudio, внешних файлов и интернета не нужно.
